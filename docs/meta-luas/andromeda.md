## GDI font engine (reusable)

`ffi.load("gdi32")` + cdef LOGFONTW / BITMAPINFO / TEXTMETRICW; `CreateFontIndirectW → CreateCompatibleDC → CreateDIBSection → TextOutW → GdiFlush → render.load_image_rgba(buffer, size)` → cached texture drawn with `render.texture`; outline (4 offset draws), shadow (1px, alpha 128), spacing, weights 100-900, UTF-8 → UTF-16, LRU glyph cache (256 entries, purge every 30 frames / 60-frame TTL).
