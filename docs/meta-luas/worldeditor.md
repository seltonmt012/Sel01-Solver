## WorldEditorRemaper — per-map world / material editor (heavy FFI, mostly not for us)

Downloads its assets on load (`network.get("https://northon.dev/neverlose/remaper/" .. file)` → `files.write(path, data, not is_vmt)`; models `lantern_bugs / palacelightbugs / polelightbugs`, materials `irlflare`, `light_glowirl`, `bugs_noise`, `lanternbugs*`). Parses `csgo\pak01_dir.vpk` in FFI (signature 1437209140, directory entries) to list `.vtf` textures, filtered by 44 prefixes, grouped by the first path segment → Textures combo + per-group lists.

Menu `ui.sidebar("\a{Link Active}World Editor", "")`, tabs Main / Textures. Main: `Settings for: <map>` (`common.get_map_data().shortname`), Presets (list "+ Create New", Enabled, Name, Create / Edit / Delete, Points list, Back, Delete Point; enabled presets prefixed `"\a{Link Active}\aDEFAULT   "`), Point: Position (Static Props sorted by crosshair + Set), Point: Settings (Name, Position X/Y/Z ±20000, Type Particle / Model / Sprite / Beam, Model combo, Angles Offset ±300 (0 = Off) + Custom Yaw Offset, Position Z Offset, End Position Offset, Start / End Width 1-150 def 20, Scale 10-500 def 100 step 0.01, Set Angles + X/Y/Z, HDR Color Scale 1-30 def 10 step 0.1, Color, Render Mode Normal / Transparent Color Blend / Transparent Texture Blend / Glow Ignore Z / Alpha Based Transparency / Additive Glow / Additive With Frame Blending / Alpha Additive / World Glow (ints 0..9), Save), Ambient per map (Night Mode + color, Static Props + color, Post Processing + color, Fog Changer Off / Clean / Override + color / Start / Distance ±150, Illumination Off / Bright / Sunlight + Pitch 0-89 / Yaw ±179 / Distance 50-1500 / Color), Weather per map (Enabled, Type Rain / Rain 2 / Particle Rain / Particle Ash / Particle Snow, Radius 0-1500 def 1000, Width 0-100 def 50, Density 10-200 def 65). Textures tab: presets, Preset Editing list, `Material By Crosshair`, `Selected Material`, `Selected Texture`, Select Material / Select / Teleport / Save, Color, Groups combo + per-group texture lists + Select Texture.

## inport-export.lua — the cheapest config share

Group `ui.create('RU LEAKS')`; roots `ui.find("Aimbot","Ragebot")`, `("Aimbot","Anti Aim")`, `("Aimbot","Legitbot")`, `("Visuals","Players")`, `("Visuals","World")`, `("Visuals","Inventory")`, `("Miscellaneous","Main")`; `group:listable('Tabs', names)` picks which to include; Export = `clipboard.set(base64.encode(json.stringify({[tab] = handle:export()})))`; Import = reverse with `handle:import(v)` in pcall. **NL tab / group handles expose `:export()` / `:import(json)` natively.**
